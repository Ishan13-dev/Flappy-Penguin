# 🐧 Flappy Penguin

A fun, CSS-powered penguin animation project with a playful environment.  
This project demonstrates creative use of **HTML & CSS** to build a responsive, interactive penguin character with animated arms, mountains, sun, and ground.

## 🚀 Live Demo
Check out the project here:  
👉 [Flappy Penguin](https://ishan13-dev.github.io/Flappy-Penguin/)

## 📂 Project Structure
- **index.html** → Contains the penguin, mountains, sun, and ground elements.
- **styles.css** → Handles the styling, animations, and responsiveness.

## 🎨 Features
- Penguin built entirely with **CSS shapes**.
- Interactive animation (penguin waves when clicked).
- Responsive design for desktop, tablet, and mobile.
- Scenic background with mountains, sun, and ground.

## 🛠️ Technologies Used
- **HTML5**
- **CSS3** (Flexbox, gradients, animations, media queries)

## 📱 Responsiveness
- Uses `vw` and `vh` units for scaling.
- Media queries ensure proper layout on different screen sizes.
